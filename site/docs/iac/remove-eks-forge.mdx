# How to Remove EKS Forge

This guide shows you how to destroy every AWS resource EKS Forge created, from both your [live fork](/docs/deployment/get-started/live-repository-setup/#fork-the-live-repository) and [catalog fork](/docs/quickstart/installation/#fork-the-eks-forge-catalog).

:::warning
Only do this if you want to remove EKS Forge from your AWS account entirely. Once the bootstrap resources are destroyed, you need to run the [Quickstart](/docs/quickstart/) and the [Live Repository Setup](/docs/deployment/get-started/live-repository-setup/) again to deploy.
:::
